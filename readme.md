Sistema web educativo orientado a estudiantes que, debido a una incapacidad médica, no pueden asistir presencialmente a clases y necesitan continuar con su proceso académico desde casa.

# 🎯 Descripción del proyecto

**Aprenzy** es una plataforma web educativa desarrollada para apoyar a estudiantes que presentan una incapacidad médica y no pueden asistir temporalmente a clases presenciales.

El sistema permite que los estudiantes continúen con su proceso académico desde casa, teniendo acceso a guías de aprendizaje, actividades, materiales de apoyo y diferentes recursos relacionados con sus cursos y materias.

Además, la plataforma permite gestionar usuarios, cursos, materias, incapacidades, actividades, materiales, entregas y demás información académica, facilitando el seguimiento del proceso educativo entre estudiantes y docentes.

---

# 🧩 Problema

Cuando un estudiante presenta una incapacidad médica, no puede asistir normalmente a las clases presenciales y puede perder información importante, actividades, explicaciones y materiales proporcionados por los docentes.

Esta situación puede generar:

- 📌 Atraso académico.
- 📌 Acumulación de trabajos.
- 📌 Pérdida de información importante.
- 📌 Dificultades para ponerse al día al regresar a la institución.
- 📌 Estrés debido a la acumulación de actividades académicas.
- 📌 Dificultades de comunicación entre estudiantes y docentes.

---

# 💡 Solución propuesta

Se propone el desarrollo de un sistema web denominado **APRENZY**, cuyo objetivo es permitir la continuidad del proceso académico de los estudiantes durante el período de incapacidad médica.

La plataforma contempla las siguientes funcionalidades:

- ✔️ Gestión de usuarios.
- ✔️ Gestión de estudiantes y docentes.
- ✔️ Registro e inicio de sesión.
- ✔️ Gestión de cursos.
- ✔️ Gestión de materias.
- ✔️ Relación entre usuarios y cursos.
- ✔️ Relación entre docentes y materias.
- ✔️ Registro y gestión de incapacidades médicas.
- ✔️ Historial de incapacidades.
- ✔️ Gestión de apelaciones.
- ✔️ Gestión de accesos académicos.
- ✔️ Acceso a materiales académicos.
- ✔️ Gestión de actividades.
- ✔️ Gestión de entregas.
- ✔️ Seguimiento de actividades académicas.
- ✔️ Facilitar la comunicación entre docentes y estudiantes.
- ✔️ Permitir la continuidad del proceso académico desde casa.

# ⚙️ Tecnologías utilizadas

El proyecto Aprenzy está desarrollado utilizando diferentes tecnologías para la construcción del frontend, backend, base de datos y gestión del proyecto.

## 🎨 Frontend

- **React** — Biblioteca principal utilizada para construir la interfaz de usuario.
- **React DOM** — Integración de React con el DOM del navegador.
- **TypeScript** — Lenguaje utilizado para agregar tipado estático y mejorar la mantenibilidad del código.
- **Vite** — Herramienta utilizada para el desarrollo y construcción del frontend.
- **Bootstrap** — Framework utilizado para el diseño y estilos de la interfaz.
- **React Icons** — Biblioteca utilizada para incorporar iconos en la interfaz.

## 🔧 Backend

- **Python** — Lenguaje principal utilizado para el desarrollo del backend.
- **FastAPI** — Framework utilizado para construir la API REST.
- **Uvicorn** — Servidor ASGI utilizado para ejecutar la aplicación FastAPI.
- **Pydantic** — Biblioteca utilizada para la validación y estructuración de datos.
- **Pytest** — Framework utilizado para realizar pruebas automatizadas.

## 🗄️ Base de datos

- **MySQL** — Sistema de gestión de bases de datos utilizado para almacenar la información de la plataforma.

## 🛠️ Herramientas

- **npm** — Gestor de paquetes utilizado para administrar las dependencias del frontend.
- **Git** — Sistema de control de versiones.
- **GitHub** — Plataforma utilizada para almacenar y gestionar el repositorio del proyecto.
